# GreenPulse

**A Community Climate Action and Environmental Monitoring Application**

## Project Overview

GreenPulse is a mobile application that supports **United Nations Sustainable Development Goal 13 (SDG 13): Climate Action**. It aims to help community residents report environmental concerns, access available environmental information, track the progress of submitted reports, and participate in local climate action activities.

## Problem Statement

Communities need an accessible and organized way to report environmental concerns, monitor the progress of reported issues, access relevant environmental information, and coordinate local climate action activities. GreenPulse aims to address these needs through a centralized mobile application that connects residents and community administrators.

## Target Users

- **Community Residents:** Report environmental concerns, view available environmental information, track report statuses, and participate in community activities.
- **Community Administrators:** Review submitted reports, update report statuses, publish environmental advisories, and manage community activities.

## Core Features

1. User registration and authentication
2. Environmental issue reporting with photos and location information
3. Report confirmation and status tracking
4. Environmental information and community map
5. Community cleanup and tree-planting activities
6. Notifications and climate advisories
7. Administrator dashboard for report management
8. Privacy and account settings

*Features are proposed and may change as development progresses.*

## Installation and Setup

### Prerequisites

- Node.js and npm
- Git
- Expo Go or a compatible development build

### Steps

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd GreenPulse
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Open the application using Expo Go or a compatible development build.

*These steps assume the repository contains a configured Expo application and a valid `package.json`.*
